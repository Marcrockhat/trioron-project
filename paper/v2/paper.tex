\begin{abstract}
% TODO: rewrite once the §4 Results are settled. Placeholder sets the
% framing: this paper documents the architectural changes between
% v1.0 (a three-state node with growth/pruning/EWC/dream-replay) and
% v1.1 (six per-cell substrate axes plus a pool-matched composition
% mechanism), not a new continual-learning benchmark result.
We describe \emph{Trioron 1.1}, a substrate-level revision to the
trioron architecture introduced in the companion paper, exposing six per-cell
axes of structural plasticity: long-range input reach, plastic fanout
sparsity, depth growth, slow axonal gain, dendritic
compartmentalization, and field-conditional layer emergence. The
six axes share one design principle --- each is a separate write
channel into the substrate, with its own provenance and its own
plasticity gate, rather than a feature of the loss or the optimizer.
A small spatial primitive (positions on a unit square, partitioned
into pools) then enables a cell-granularity composition operator:
two organisms trained independently on disjoint task slices can be
absorbed into one substrate without retraining when they share the
L0 perception layer's deterministic factor (the R$\cdot$S
handshake). The cell-granularity composition is compatible with
positional locality constraints (locally-connected masks) because
absorption respects pools, not exact positions. We report the
mechanism's first verification on a chained-15 disjoint-class slice:
task-aware accuracy is preserved on both donors within
$\Delta \leq 0.026$, full-softmax accuracy lifts by $+0.20$ to
$+0.31$ via manifold merge plus a 200-step head-only calibration
pass, and the post-absorption substrate is \emph{more} locality-clean
than either donor alone. The 1.1 substrate is backwards-compatible
with 1.0 donors: legacy checkpoints load unchanged and run under the
extended forward path with the new axes at their default-off
settings.
% End of placeholder abstract.
\end{abstract}

\subsection{Pool-matched absorption}
\label{sec:absorption}

% TODO: the architectural unlock. v1.0 absorption operated at branch
% granularity (Branch + MultiBranchOrganism) and required donors to
% share the L0 perception layer's exact weights (R·S handshake at
% L0). v1.1 adds cell-granularity absorption: every donor cell is
% appended to the recipient at its corresponding pool. Donor and
% recipient must share the upstream layer's width (the R·S handshake)
% and the head's class space; under those constraints, absorbed
% cells inherit the recipient's mask convention (LCN extension) and
% slot into the recipient's pool structure.
%
% The composition is the four-mechanism stack:
%   1. pool_matched_absorb : transfer W rows + head columns + b
%   2. selective head merging : zero out donor head columns for
%      classes the donor never trained on
%   3. merge_manifold : combine per-class (μ, σ) signatures
%   4. settle_head_via_manifold : 200-step head-only calibration
%      under manifold replay
%
% First verification: chained-15 disjoint slice, donor A on classes
% 0-3, donor B on classes 4-7, both with LCN-on-L1 (soft σ=0.25,
% k=8). Task-aware preserved within Δ ≤ 0.026 on both donors; full-
% softmax lifts +0.20 to +0.31; post-absorb locality 0.78+ (vs
